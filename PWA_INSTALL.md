# 📱 Установка PoopTracker как PWA

PoopTracker теперь является Progressive Web App (PWA)! Это значит, что вы можете установить его на свой телефон как обычное приложение.

## 🤖 Установка на Android

### Через Chrome:
1. Откройте сайт в Chrome: `https://evgenymayorov.github.io/PoopTracker/`
2. Нажмите на **три точки** в правом верхнем углу
3. Выберите **"Установить приложение"** или **"Добавить на главный экран"**
4. Подтвердите установку
5. Иконка 💩 появится на рабочем столе!

### Через Samsung Internet:
1. Откройте сайт
2. Нажмите на **меню** (три полоски)
3. Выберите **"Добавить страницу"** → **"На экран"**

## 🍎 Установка на iPhone/iPad

### Через Safari:
1. Откройте сайт в Safari: `https://evgenymayorov.github.io/PoopTracker/`
2. Нажмите на кнопку **"Поделиться"** (квадрат со стрелкой вверх) внизу экрана
3. Прокрутите вниз и выберите **"На экран «Домой»"**
4. Нажмите **"Добавить"**
5. Приложение появится на рабочем столе!

⚠️ **Важно:** На iOS PWA работает только через Safari. Chrome и другие браузеры не поддерживают установку PWA на iPhone.

## ✨ Преимущества PWA

- 🚀 **Быстрый запуск** - открывается как нативное приложение
- 📴 **Работает офлайн** - кэширует файлы и работает без интернета
- 🔔 **Уведомления** - push-уведомления когда друзья "сходили"
- 📱 **Полноэкранный режим** - без адресной строки браузера
- 💾 **Не занимает место** - весит меньше нативного приложения

## 🎨 Генерация PNG иконок

Для полноценной PWA иконки (вместо SVG) выполните следующие шаги:

1. Откройте в браузере: `https://evgenymayorov.github.io/PoopTracker/generate-icons.html`
2. Нажмите **"Скачать 192x192"** → сохраните как `icon-192.png` в папку `public/`
3. Нажмите **"Скачать 512x512"** → сохраните как `icon-512.png` в папку `public/`
4. Запушьте изменения:
   ```bash
   git add public/icon-192.png public/icon-512.png
   git commit -m "Add PWA icons"
   git push
   ```

## 🔧 Технические детали

### Манифест приложения
Файл `public/manifest.json` содержит:
- **name**: PoopTracker
- **short_name**: PoopTracker
- **theme_color**: #1e1b4b (тёмно-фиолетовый)
- **background_color**: #1e1b4b
- **display**: standalone (полноэкранный режим)
- **icons**: SVG иконка

### Сервис-воркер
- Автоматически кэширует все файлы приложения
- Кэширует запросы к Supabase (NetworkFirst стратегия)
- Автоматически обновляется при изменении файлов

### Мета-теги iOS
В `index.html` добавлены:
- `apple-mobile-web-app-capable` - полноэкранный режим
- `apple-mobile-web-app-status-bar-style` - стиль статус-бара
- `apple-mobile-web-app-title` - название приложения

## 🐛 Решение проблем

### Android: кнопка установки не появляется
- Убедитесь, что используете Chrome
- Попробуйте обновить страницу
- Проверьте, что сайт открыт по HTTPS

### iOS: приложение не устанавливается
- Используйте только Safari (не Chrome!)
- Убедитесь, что сайт открыт по HTTPS
- Попробуйте очистить кэш Safari

### Иконка не отображается
- Сгенерируйте PNG иконки через `generate-icons.html`
- Запушьте их в репозиторий
- Дождитесь деплоя
